I have an identity-service API for importing access roles.

Import endpoint:
POST /api/v1/access-roles/import?format=json
POST /api/v1/access-roles/import?format=csv

The import supports JSON and CSV.

Each imported access role row can have these fields:
- externalRef: optional stable reference used by childRoleRefs
- name: required string
- displayName: optional string
- description: optional string
- type: required string, examples: business, technical
- status: optional string, example: ACTIVE
- businessUnit: optional string
- organization: required UUID, references org_units.id
- businessFunction: optional string
- classification: optional list of strings
- complianceTags: optional list of strings
- riskLevel: optional string, examples: low, medium, high
- riskReason: optional string
- ownerId: optional UUID
- requestable: optional boolean
- requireApproval: optional boolean
- certificationSchedule: optional string, examples: MONTHLY, QUARTERLY, ANNUALLY
- entitlementIds: optional list of UUIDs
- childRoleIds: optional list of existing access-role UUIDs
- childRoleRefs: optional list of externalRef values from other rows in same import
- identityIds: optional list of identity UUIDs to assign this imported role to
- rules: optional JSON array of assignment rules

Important behavior:
- organization is mandatory for every imported role row.
- identityIds is optional.
- If identityIds is provided, after the role is created and childRoleRefs are wired, the system assigns that imported role to those identities.
- Those identity role assignments are created with source_type = IMPORT.
- Role-derived entitlements from the parent role and inherited child roles are applied with source = IMPORT.
- childRoleRefs are resolved by matching externalRef values within the same import file.
- For CSV, multi-value fields must be pipe-delimited using |.
- For CSV, the rules column may contain a JSON array and must be CSV-escaped if it has commas or quotes.

JSON format:
The JSON import can be either:
1. An object with roles array:
{
